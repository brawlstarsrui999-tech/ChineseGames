# ChineseGames 🀄

Android-приложение на **Kotlin + Jetpack Compose** для **повторения уже выученного китайского языка** в игровой форме.
Неоновая и пастельная аниме-пиксельная тема, тихая фоновая музыка, синтезированные звуки, анимации, вибрации —
и всё полностью **офлайн**, без интернета, аккаунтов и рекламы.

> Словарь наполняет сам пользователь: приложение ничего не подсказывает и никуда не лезет.

---

## Что уже готово

### 1. Словарь (раздел «Словарь»)
* **Неограниченное количество папок** («Еда», «HSK 3», «Путешествия»…) со своим эмодзи.
* Внутри папки — **неограниченное количество слов**: `汉字`, `пиньинь`, `перевод на русский`.
* Поиск по папкам и по словам, изменение и удаление, прогресс выученного по каждой папке.
* ⭐ **Избранное** — звёздочка у любого слова (кнопка или пункт меню), а в списке папок появляется
  отдельная строка «Избранное». По этому набору можно играть как по обычной папке.
* 🔥 **Сложные слова** — автоматический набор из слов с самой низкой точностью (до 40 штук).
* 🔊 Озвучка иероглифа системным TTS (китайский голос Google).

### 2. Игры (раздел «Игры») — восемь тренировок

| Игра | Как играется |
|---|---|
| 🃏 **Найди пару** | три режима: классика, «русский → 汉字» и «🔊 аудио → 汉字»; комбо, 3 подсказки, таймер, очки |
| 🧩 **Мемори-сетка** | пары показываются несколько секунд, потом закрываются — дальше только память, без подсказок |
| 🧠 **Memory-цепочка** | показали 3 слова, спрятали — вспоминаем, что с чем было связано |
| 🫧 **Bubble pop** | пузыри с переводами поднимаются вверх: нужно лопнуть правильный, пока он не улетел |
| 🌠 **Падающие слова** | иероглиф медленно падает — успейте выбрать перевод, пока он не упал |
| ⚡ **Спринт на время** | 60 секунд, сколько слов угадаете подряд; ошибка сбрасывает серию |
| 🎧 **Аудио-квиз** | слово произносится вслух — выбираем прозвучавший иероглиф |
| ⌨️ **Ввод пиньиня** | видим иероглиф — печатаем пиньинь (тоны можно не писать, `ü` = `v`) |

Общее для всех игр:

* **Настройка партии** перед стартом: какие папки брать (можно «Избранное» и «Сложные слова»),
  сколько слов/пар, сколько вариантов ответа, лимит времени, а для «Мемори-сетки» — сколько секунд показывать пары.
* **Слова берутся из словаря** одинаково во всех играх, случайно из всех выбранных папок сразу.
* **Интервальное повторение**: при раздаче (галочка «Сначала слова с низкой точностью»)
  первыми идут слова с худшей точностью и те, что давно не попадались, — так слабые слова повторяются чаще.
* Комбо, очки со скоростным бонусом, звёзды за точность, экран победы с конфетти и кнопками
  «Ещё раз (новые слова)» / «Повторить эти же слова».
* **Карточки подстраиваются под экран** (без прокрутки игрового поля): на поле помещается
  до 30 пар сразу, размер карточек и шрифта считается автоматически.
* Ошиблись в «Найди пару» — **обе карточки остаются открытыми несколько секунд**,
  чтобы вы успели запомнить, где что лежит. Только потом закрываются.

### 3. Прогресс и статистика
* **Статистика по дням**: столбики по последним 14 дням (минуты, ответы, ошибки), итоги, рекорд очков.
* Прогресс по каждой папке: сколько слов и сколько уверенно знаете (точность ≥ 75%).
* **Список слабых слов** прямо в статистике + кнопка «Тренировать слабые слова»
  (запускает спринт по этому набору).
* Вся статистика — в SQLite (Room): партии, ответы, точность, комбо, время, звёзды.

### 4. Экспорт и импорт словаря в CSV
* Раздел «Настройки» → «Словарь в CSV»: экспорт в файл (`папка;эмодзи;иероглиф;пиньинь;перевод`, UTF-8 с BOM —
  открывается в Excel и Google Таблицах).
* Импорт: читает CSV (разделитель `;`, `,` или табуляция), создаёт папки по названиям
  и пропускает дубликаты. Работает через системный выбор файла (SAF) — без разрешений.

### 5. Оформление, музыка и звук
* **Тема «день/ночь»** — переключается в настройках: ночная (глубокий фиолетовый неон) и дневная
  (светлая аниме-пастель). Переключение мгновенное и затрагивает все экраны, включая музыку.
* **Анимешно-пиксельные детали**: лепестки сакуры и пиксельные облака на фоне, пиксельные спрайты
  (сакура, фонарик, панда, кошка, звёздочки), пиксельные рамки, разделители, бейджи и «мудрость кота» на экранах.
* **Тихая фоновая музыка** (два бесшовно зацикленных трека в китайской пентатонике — спокойная ночная
  и светлая дневная). Громкость намеренно ниже озвучки иероглифов, есть отдельный регулятор
  и переключатель (кнопка 🎵 на главном экране и в настройках). Пока звучит иероглиф, музыка приглушается,
  а при сворачивании приложения — останавливается.
* **9 синтезированных звуков**: клик, переворот, совпадение, комбо, ошибка, фанфара, звезда,
  свист перехода, «поп» для пузырей. Переключатель 🔊 запоминается.
* 3D-переворот карточек, пружинные нажатия, тряска при ошибке, конфетти, «дыхание» логотипа.
* Вибрация (haptic feedback) на совпадениях и ошибках.

## Как открыть и запустить

1. **Android Studio** (Ladybug / Meerkat и новее) → `File → Open` → выберите папку **`ChineseGames`**.
2. Дождитесь Gradle Sync (студия сама создаст `local.properties` с путём к SDK).
3. Подключите телефон (Android 8.0+/API 26+) или запустите эмулятор.
4. **Run ▶** — приложение установится и запустится.

Сборка из терминала:

```bash
./gradlew :app:assembleDebug      # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:installDebug       # сразу установить на подключённое устройство
```

**Требования:** JDK 17, Android SDK 35, Gradle 8.9 (обёртка `gradlew` уже в проекте).
Стек: Kotlin 2.0.21 · Compose BOM 2024.12.01 · Material 3 · Navigation Compose · Room 2.6.1 (KSP) · Coroutines/Flow.

```
│   └── BackgroundMusic.kt          — луповая музыка: громкость, вкл/выкл, приглушение, пауза

│   ├── StudyOrder.kt                — «сначала слова с низкой точностью»
│   ├── CsvCodec.kt                  — разбор и сборка CSV для экспорта/импорта
│   ├── SettingsStore.kt             — настройки (тема, музыка, звук, интервальное повторение)
│   ├── DeckDao.kt / WordDao.kt / FavoriteDao.kt — доступ к папкам, словам и избранному
│   ├── StatsDao.kt / DeckRepository.kt — запросы статистики и вся логика словаря
│   └── AppDatabase.kt               — база v2 + миграция
└── ui/
    ├── theme/                      — двойная палитра (ночь/день), типографика, ComposeLocal'ы
    ├── components/                 — стекло, кнопки, диалоги, фон, пиксельные спрайты и декор,
    │                                 общая сетка карточек, компоненты викторин
    ├── game/                       — движки: MatchViewModel (пары/мемори), QuizViewModel
    │                                 (пузыри, падение, спринт, аудио, цепочка), PinyinViewModel
    ├── navigation/                 — маршруты всех экранов и игр
    └── screens/                    — меню, словарь, папка, хаб игр, настройка партии,

```

Полезные файлы:

* `tools/generate_sounds.py` — **генератор звуков** (numpy + soundfile → OGG).
* `tools/generate_music.py` — **генератор фоновой музыки** (два бесшовных лупа → OGG).
* `tools/generate_icons.py` — **генератор иконок** (Pillow + Noto CJK → все mipmap-плотности).
* `app/src/main/res/raw/*.ogg` — сами звуки и музыка, можно заменить своими (имена те же).

```bash
python3 tools/generate_sounds.py    # перегенерировать звуки
python3 tools/generate_music.py     # перегенерировать музыку
python3 tools/generate_icons.py     # перегенерировать иконку
```

## Озвучка иероглифов

Кнопка 🔊, режим «Аудио → 汉字» и «Аудио-квиз» используют системный **TextToSpeech**.
Чтобы китайский звучал правильно, поставьте китайский голос:
*Настройки → Система → Языки и ввод → Синтез речи → Google → установить китайский (Китай, мандарин).*
Если голоса нет — приложение работает без озвучки (в «Аудио-квизе» покажется пиньинь-подсказка),
и это видно в настройках в разделе «Озвучка».
