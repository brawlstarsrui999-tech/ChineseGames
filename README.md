# ChineseGames 🀄

Android-приложение на **Kotlin + Jetpack Compose** для **повторения уже выученного китайского языка** в игровой форме.
Фиолетовая неоновая тема, живой фон, звуки, анимации, вибрации — и всё полностью офлайн, без интернета и без рекламы.

> Словарь наполняет сам пользователь: приложение ничего не подсказывает и никуда не лезет.

---

## Что уже готово

### 1. Словарь (раздел «Словарь»)
* Создавайте **неограниченное количество папок** («Еда», «HSK 3», «Путешествия»…).
* У каждой папки — своё эмодзи-обозначение.
* Внутри папки — **неограниченное количество слов**, у каждого три поля:
  1. **Иероглиф** — `你好`
  2. **Пиньинь** — `nǐ hǎo`
  3. **Перевод на русский** — `привет`
* Поиск по папкам и по словам, изменение и удаление чего угодно, прогресс выученного по каждой папке.
* Кнопка 🔊 у каждого слова — озвучка иероглифа системным TTS (китайский голос Google).

### 2. Игры (раздел «Игры»)

**Найди пару** — основная игра:

1. Нажимаете «Играть» → открывается окно настройки партии.
2. Выбираете **одну или несколько папок** (галочками, по умолчанию выбраны все).
3. Слайдером или чипами задаёте **число карт** (от 3 до 30 пар, то есть от 6 до 60 карточек).
4. Приложение берёт **случайные слова из всех выбранных папок сразу** (даже если в папках хранится больше слов, чем нужно — выбор случайный).
5. Игровое поле: закрытые карточки. Переворачиваете по две:
   * **карточка иероглифа** — 汉字 крупно, под ним пиньинь;
   * **карточка перевода** — русское значение.
   Совпало — пара ваша (карточка «зеленеет» и озвучивается), не совпало — карточки трясутся и закрываются обратно.
6. Победа — когда найдены пары **всем** карточкам. Дальше экран победы: конфетти, звёзды за точность, очки, время, комбо и кнопки «Ещё раз (новые слова)» / «Повторить эти же слова».

Режимы партии:
| Режим | Как играется |
|---|---|
| 🃏 **Классика** | все карточки закрыты — чистая память |
| 🈶 **Русский → 汉字** | иероглифы открыты сразу: подбираем к русскому слову нужный иероглиф |
| 🎧 **🔊 Аудио → 汉字** | карточка-звук закрыта, при перевороте слово произносится — ищем его иероглиф на слух |

Дополнительно в игре: **комбо** за пары подряд (очки растут), **3 подсказки** на партию, таймер,
счёт очков, штраф за ошибки и авто-пауза, если свернуть приложение.

Разделы «Аудио-квиз» и «Мемори-сетка» помечены как «скоро» — каркас под них уже есть.

### 3. Оформление и «имба»-часть
* Глубокая фиолетовая палитра, градиенты, «стеклянные» карточки, неоновые границы.
* Живой фон: плавающие светящиеся орбы и звёздная пыль (Canvas-анимация, без картинок).
* 3D-переворот карточек (`rotationY` + `cameraDistance`), пружинные нажатия, тряска при ошибке.
* Конфетти на экране победы, «дыхание» логотипа, анимация звёзд.
* **8 синтезированных звуков**: клик, переворот, совпадение, комбо, ошибка, фанфара, звезда, свист перехода.
  Кнопка 🔊 в правом верхнем углу главного экрана выключает/включает звук (настройка запоминается).
* Вибрация (haptic feedback) при совпадении пары.
* Вся статистика — в SQLite (Room): партии, найденные пары, точность, лучший счёт, % выученных слов.

## Как открыть и запустить

1. **Android Studio** (Ladybug / Meerkat и новее) → `File → Open` → выберите папку **`ChineseGames`**.
2. Дождитесь Gradle Sync (студия сама создаст `local.properties` с путём к SDK).
3. Подключите телефон (Android 8.0+/API 26+) или запустите эмулятор.
4. **Run ▶** — приложение установится и запустится.

Сборка из терминала:

```bash
./gradlew :app:assembleDebug      # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:installDebug       # сразу установить на подключённое устройство
```

**Требования:** JDK 17, Android SDK 35, Gradle 8.9 (обёртка `gradlew` уже в проекте).
Стек: Kotlin 2.0.21 · Compose BOM 2024.12.01 · Material 3 · Navigation Compose · Room 2.6.1 (KSP) · Coroutines/Flow.

## Структура проекта

```
app/src/main/java/com/chinesegames/app/
├── MainActivity.kt                 — вход, edge-to-edge, провайдер звука и озвучки
├── ChineseGamesApplication.kt      — база, репозиторий, звуки, TTS
├── audio/
│   ├── GameSounds.kt               — SoundPool + 8 эффектов + переключатель звука
│   └── ChineseSpeaker.kt           — озвучка иероглифов (TextToSpeech, zh-CN)
├── data/                           — Room: Deck, Word, GameWordStat, MatchResult + DAO + репозиторий
└── ui/
    ├── theme/                      — палитра, типографика, тема
    ├── components/                 — стекло, кнопки, диалоги, фон, конфетти, игровая карточка
    ├── game/MatchViewModel.kt      — движок «Найди пару»
    ├── navigation/                 — маршруты и график экранов
    └── screens/                    — меню, словарь, папка, хаб игр, настройка партии, игра
```

Полезные файлы:

* `tools/generate_sounds.py` — **генератор звуков** (numpy + soundfile → OGG). Меняете параметры — звучит по-новому.
* `tools/generate_icons.py` — **генератор иконок** (Pillow + Noto CJK → все mipmap-плотности).
* `app/src/main/res/raw/*.ogg` — сами звуки, можно заменить своими (имена те же).

```bash
python3 tools/generate_sounds.py    # перегенерировать звуки
python3 tools/generate_icons.py     # перегенерировать иконку
```

## Озвучка иероглифов

Кнопка 🔊 и режим «Аудио → 汉字» используют системный **TextToSpeech**.
Чтобы китайский звучал правильно, поставьте китайский голос:
*Настройки → Система → Языки и ввод → Синтез речи → Google → установить китайский (Китай, мандарин).*
Если голоса нет — приложение просто работает без озвучки, ничего не ломается.

## Идеи для развития

* Игры «Аудио-квиз» (слушай → выбирай иероглиф) и «Мемори-сетка» — карточки в хабе уже готовы.
* Интервальное повторение: уже сейчас каждому слову считается `accuracy`, осталось
  добавить правило «сначала слова с низкой точностью» при раздаче карточек.
* Экспорт/импорт словаря в CSV, папка «Избранное», статистика по дням, тема «день/ночь».
