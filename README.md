# ChineseGames 🀄

Android-приложение на **Kotlin + Jetpack Compose** для изучения и повторения китайского языка в игровой форме.
Основная часть работает офлайн: бесплатные курсы HSK, словарь, игры, статистика и TTS. Интернет нужен только для необязательных вещей: оплаты косметических улучшений через Robokassa, одного рекламного баннера и входа Google для облачной синхронизации.

> **Обучение полностью бесплатно.** Магазин содержит только необязательные украшения, свой фон, талисман и отключение рекламы — ни один урок, уровень, слово или режим игры не продаётся.

Основные разделы — в нижней панели: **Главная · Словарь · Игры · Курс · Прогресс · Ещё**.

## Возможности

### Словарь и папки HSK

- Неограниченное количество пользовательских папок и слов (`汉字`, пиньинь, русский перевод), поиск, импорт и экспорт CSV.
- ⭐ **Избранное** и 🔥 **Сложные слова** — быстрые наборы для любой игры.
- ✅ Системная папка **«Выученное»**: курс помещает туда группы, пройденные на 100 %.
- В словаре с первого запуска открыты **7 папок HSK 1 … HSK 7**. В каждой — подпапки-разделы курса с ровно теми же словами, поэтому можно выбрать весь уровень или отдельную тему и играть по ней.
- Системные HSK-папки не блокируются, не удаляются и не требуют покупки.

### Игры — 10 режимов

| Игра | Как играется |
|---|---|
| 🃏 **Найди пару** | три режима: классика, «русский → 汉字» и «🔊 аудио → 汉字»; комбо, подсказки, очки |
| 🧩 **Мемори-сетка** | пары ненадолго открыты, затем нужно вспомнить расположение |
| 🧠 **Memory-цепочка** | показали слова — нужно вспомнить, что с чем связано |
| 🫧 **Bubble pop** | лопайте перевод, пока пузырь не улетел |
| 🌠 **Падающие слова** | выберите перевод, пока иероглиф не упал |
| ⚡ **Спринт на время** | серия ответов за 60 секунд |
| 🎧 **Аудио-квиз** | слушаем слово и выбираем иероглиф |
| ⌨️ **Ввод пиньиня** | видим 汉字 — печатаем pīnyīn (`ü` можно ввести как `v`) |
| 🎼 **Тренажёр тонов** | слышим и видим иероглифы без пиньиня, затем нажимаем тоны каждой слоговой части; тоны берутся из настоящих знаков пиньиня (`nǐ hǎo → 3, 3`, `zǎo ān → 3, 1`) |
| 👐 **Без рук** | случайная карточка сама переворачивается через выбранный интервал, произносится по-китайски и по-русски, цикл идёт до выключения |

Перед активной партией можно выбрать папки, число вопросов/пар, число вариантов, время, режим отображения слов и интервальное повторение. Для «Без рук» интервал выбирается пользователем (3–30 секунд): есть пауза, пропуск и повтор озвучки; экран не засыпает.

Все игры используют одну систему точности, комбо, звёзд и статистики. Слабые и давно не встречавшиеся слова могут выдаваться первыми.

### Курс HSK 1 → HSK 7

В разделе **«Курс»** — **7 422 уникальных слова**:

| Уровень | Слов |
|---:|---:|
| HSK 1 | 150 |
| HSK 2 | 147 |
| HSK 3 | 298 |
| HSK 4 | 598 |
| HSK 5 | 1 300 |
| HSK 6 | 2 500 |
| **HSK 7** | **2 429** |

- HSK 7 — качественная подборка часто употребимых слов, выражений и учебной лексики, которой нет в HSK 1–6. Генератор проверяет отсутствие дублей по ханцзы.
- Слова разложены по смысловым разделам и группам по 5 слов; в каждой группе знакомство с TTS и игровые тренировки.
- Группа становится выученной после прохождения всех обязательных упражнений без ошибок; затем её слова добавляются в «Выученное».
- Экзамен открывает следующий уровень. Есть также **210** учебных предложений с отдельными упражнениями.
- Материал находится в `app/src/main/assets/hsk/level1.json` … `level7.json` и `sentences.json`.

### Прогресс и файлы

- Статистика по дням, рекорды, точность, серии, время, звёзды и прогресс по папкам.
- Room/SQLite хранит партии, результаты и прогресс HSK локально.
- **CSV** в Настройках: экспортирует пользовательский словарь, импортирует папки и слова без дубликатов. Системные HSK-папки в экспорт не попадают.
- Кнопка 🔊 использует системный Chinese TextToSpeech; для хорошего звучания установите китайский голос в настройках Android.

## Оформление и необязательный магазин

Бесплатная базовая тема — фиолетовая (день/ночь), с пиксельными облаками, лепестками и мягкой фоновой музыкой. В **«Магазине украшений»** доступны только следующие необязательные продукты:

| Товар | Цена | Что открывает |
|---|---:|---|
| 🎵 Своя музыка | 99 ₽ | любой аудиофайл с устройства как фоновый трек |
| 🎨 Цветные стили | 199 ₽ | розовый, синий, красный, оранжевый, жёлтый, зелёный и голубой; фиолетовый всегда бесплатен |
| 🐉 Китайский дракон | 199 ₽ | нефритовый дракон, фонарики, монеты, узлы, тихая традиционная музыка |
| ☘️ Розовый клевер | 199 ₽ | нежный розовый сад с крупными клеверами и плавно падающими листьями, воздушная музыка арфы и колокольчиков |
| 🐾 Кловерушка — талисман | 499 ₽ | милая ушастая зверушка с клеверным воротничком, мурлычет и радуется успехам, реагирует на игру и перетаскивается в любой угол |
| 🚫 Без рекламы | 99 ₽ | навсегда скрывает один баннер на главном экране |

Палитры строятся поворотом оттенка основной фиолетовой палитры, поэтому работают на всём интерфейсе и в обеих темах. Музыка настраивается по громкости и приглушается во время TTS/реплик талисмана.

Оплата открывается в WebView **Robokassa** и подтверждается запросом статуса счёта, а не только экраном «успех». Перед покупкой приложение явно сообщает: **средства не возвращаются**. Подробная настройка и правила — [`docs/robokassa.md`](docs/robokassa.md).

## Аккаунт Google и синхронизация

В Настройках есть подготовленный вход через **Firebase Authentication + Credential Manager (Google Sign-In)**.

После входа Firestore хранит документ `users/{uid}` с:

- покупками — объединяются множеством, купленное не теряется;
- группами HSK — пройденные упражнения объединяются побитово, лучший результат и попытки не откатываются;
- экзаменами, предложениями и удобными настройками.

По умолчанию репозиторий не содержит реальных Firebase-ключей: приложение показывает понятный статус «Firebase не настроен», а локальные бесплатные функции продолжают работать. Для релиза положите настоящий `app/google-services.json` (в Git он не попадает), укажите `CG_WEB_CLIENT_ID` и настройте Firestore rules. Есть шаблон [`app/google-services.json.example`](app/google-services.json.example), полная инструкция — в [`docs/robokassa.md`](docs/robokassa.md#3-firebase-google-sign-in-и-firestore).

## Сборка и запуск

1. Откройте папку **ChineseGames** в Android Studio Ladybug / Meerkat или новее.
2. Дождитесь Gradle Sync.
3. Подключите телефон Android 8.0+ (API 26) либо запустите эмулятор.
4. Нажмите **Run ▶**.

```bash
./gradlew :app:assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:installDebug
```

Нужны JDK 17 и Android SDK 35. Основной стек: Kotlin 2.0.21, Compose BOM 2024.12.01, Material 3, Navigation Compose, Room 2.6.1, Coroutines/Flow, Firebase BoM, Credential Manager и Google Mobile Ads.

### Конфигурация секретов

`local.properties` уже игнорируется Git. В нём можно задать тестовые/боевые параметры Robokassa, Firebase client ID и реальные AdMob ID; готовые примеры и объяснение серверной подписи Robokassa — в [`docs/robokassa.md`](docs/robokassa.md). По умолчанию используются официальные тестовые ID AdMob, а `ROBOKASSA_TEST=true`.

## Структура и полезные инструменты

```text
app/src/main/java/com/chinesegames/app/
├── audio/       TTS, фоновая музыка, игровые звуки, голос талисмана
├── auth/        Firebase Google Sign-In и Firestore-синхронизация
├── billing/     Robokassa: ссылка, подпись, OpStateExt, покупки
├── ads/         баннер AdMob, скрываемый товаром «Без рекламы»
├── data/        Room, словарь, HSK, настройки, покупки
└── ui/          Compose-экраны, навигация, игры, пиксельный декор и тема
```

- `tools/generate_hsk7.py build` — пересобрать HSK 7 из зафиксированной подборки и проверить дубли.
- `tools/generate_hsk_course.py` — пересобрать HSK 1–6 и предложения.
- `tools/generate_music.py` — базовые бесшовные фоновые треки.
- `tools/generate_style_audio.py` — традиционная китайская и воздушная клеверная музыка.
- `tools/generate_cloverushka_audio.py` — звериные мурр-трели и чирпы Кловерушки.
- `tools/generate_sounds.py` — базовые мягкие игровые эффекты.
- `tools/check_syntax.py` и `tools/check_refs.py` — статические проверки Kotlin без Android SDK.

```bash
python3 tools/generate_hsk7.py build
python3 tools/generate_style_audio.py
python3 tools/check_syntax.py
python3 tools/check_refs.py
```
